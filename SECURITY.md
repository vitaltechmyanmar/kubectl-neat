# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public issue.**
2. Email the maintainers or use GitHub's private vulnerability reporting feature.
3. Include the version you are using and steps to reproduce the issue.
4. You should receive a response within 7 days.

## Scope

This tool operates on local Kubernetes manifest data only. It does not communicate with clusters or handle sensitive data beyond what is already in your YAML/JSON files.
